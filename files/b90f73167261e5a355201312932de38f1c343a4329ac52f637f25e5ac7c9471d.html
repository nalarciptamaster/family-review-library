오늘의 핵심: 내 말로 바꿔 확인하기

상대가 돌려 말하거나 조건을 여러 개 말할 때, 내 말로 짧게 바꿔 말해 이해한 내용이 맞는지 확인합니다.

바꿔 말하기 확인은 상대의 말을 내 말로 짧게 다시 말하고, 맞는지 묻는 대화 방법입니다.

업무 대화에서는 상대가 부드럽게 돌려 말하거나 수량, 색상, 납기처럼 여러 조건을 한 번에 말하는 경우가 많습니다. 이때 짐작으로 넘어가지 않고 짧게 확인하면 오해를 줄일 수 있습니다.

확인 문장은 확인 표현 + 내가 이해한 내용 + right? 순서로 만듭니다.

확인 문장은 짧을수록 좋습니다. 상대의 말을 그대로 따라 하지 않고, 핵심 내용만 쉬운 단어로 바꾸어 말합니다. 못 들은 부분이 있으면 한국어로 바꾸지 않고 영어로 바로 다시 묻습니다.

확인 표현 네 가지

아래 문장은 모두 교재 예문입니다. 각 표현이 어떤 상황에 어울리는지 함께 익힙니다.

Just to clarify는 애매하게 들린 말을 확인할 때 씁니다. 교재 예문: Just to clarify, are you saying the meeting is moved to Thursday? 뜻: 확인하자면, 회의가 목요일로 옮겨졌다는 말씀이십니까?

So you mean은 상대의 말을 내 말로 짧게 바꿀 때 씁니다. 교재 예문: So you mean we need to reduce the price, right? 뜻: 그러니까 저희가 가격을 낮춰야 한다는 말씀이 맞습니까?

Let me make sure I understand는 조건이 여러 개일 때 한꺼번에 정리해서 확인할 때 씁니다. 교재 예문: Let me make sure I understand. You need 300 boxes in blue by June 10, right? 뜻: 제가 제대로 이해했는지 확인하겠습니다. 6월 10일까지 파란색 상자 300개가 필요하시다는 말씀이 맞습니까?

Correct me if I'm wrong은 내 이해가 틀렸을 수도 있다고 부드럽게 말하면서 확인할 때 씁니다. 교재 예문: Correct me if I'm wrong, but the budget is fixed, right? 뜻: 제가 틀렸다면 바로잡아 주십시오. 예산은 정해져 있다는 말씀이 맞습니까?

revisit은 다시 살펴보다, 재검토하다라는 뜻입니다. 돌려 말하는 표현을 확인할 때 자주 함께 나옵니다. 교재 예문: So you mean we should revisit the budget, right? 뜻: 그러니까 예산을 다시 검토해야 한다는 말씀이 맞습니까?

여러 조건을 한 번에 확인하는 대화

교재 예문 대화입니다. 고객과 공급업체 담당자가 주문 조건을 확인하는 장면입니다.

Client: We'd like 300 boxes in blue, and we need them by June 10. (고객: 파란색 상자 300개를 원하고, 6월 10일까지 필요합니다.)

Supplier: Let me make sure I understand. You need 300 boxes in blue by June 10, right? (공급업체: 제가 제대로 이해했는지 확인하겠습니다. 6월 10일까지 파란색 상자 300개가 필요하시다는 말씀이 맞습니까?)

Client: Yes, that's right. But we might need to rethink the size. (고객: 네, 맞습니다. 그런데 크기는 다시 생각해 봐야 할 것 같습니다.)

Supplier: Sorry, I missed the last part. Could you say that again? (공급업체: 죄송합니다, 마지막 부분을 놓쳤습니다. 다시 말씀해 주시겠습니까?)

Client: We might need to rethink the size. (고객: 크기를 다시 생각해 봐야 할 것 같습니다.)

Supplier: So you mean you want a different box size, right? (공급업체: 그러니까 다른 크기의 상자를 원하신다는 말씀이 맞습니까?)

Client: Exactly. A smaller one. (고객: 바로 그렇습니다. 더 작은 것으로 부탁합니다.)

이 대화에서 공급업체 담당자는 세 가지 일을 합니다. 첫째, 여러 조건을 한 문장으로 정리해 확인합니다. 둘째, 못 들은 부분을 영어로 바로 다시 묻습니다. 셋째, 돌려 말한 rethink the size를 want a different box size라는 쉬운 말로 바꾸어 확인합니다.

헷갈리기 쉬운 형태

아래 각 문단은 피할 형태를 먼저, 자연스러운 형태를 다음에 보여 드리고, 바로 뒤에 이유를 적었습니다. 모두 교재 예문입니다.

교재 예문 1. 피할 형태: We can ready by Friday. 자연스러운 형태: We can be ready by Friday. 이유: can 뒤에는 동사 원형이 와야 하므로, 형용사 ready 앞에 be를 넣어 can be ready라고 말합니다.

교재 예문 2. 피할 형태: If you choice express delivery, we can ship on Monday. 자연스러운 형태: If you choose express delivery, we can ship on Monday. 이유: choice는 선택이라는 명사이고, 고르다라는 동작은 동사 choose로 말합니다.

교재 예문 3. 피할 형태: We need the files until Friday. 자연스러운 형태: We need the files by Friday. 이유: 마감을 말할 때는 그때까지 끝낸다는 뜻의 by를 씁니다. until은 그때까지 어떤 상태가 계속된다는 뜻입니다.

교재 예문 4. 피할 형태: The blue boxes already out of stock. 자연스러운 형태: The blue boxes are out of stock. 이유: out of stock은 상태를 나타내므로 주어 뒤에 are 같은 be동사가 필요합니다.

못 들은 부분을 영어로 다시 묻기

확인하려면 먼저 내용을 들어야 합니다. 일부를 놓쳤을 때는 전체를 다시 요청하기보다 놓친 부분만 짚어서 묻는 것이 자연스럽습니다.

교재 예문: Sorry, could you repeat the delivery date? 뜻: 죄송합니다만, 납기일을 다시 말씀해 주시겠습니까?

교재 예문: Sorry, I missed the last part. How many units? 뜻: 죄송합니다, 마지막 부분을 놓쳤습니다. 몇 개라고 하셨습니까?

다시 들은 뒤에는 짧게 확인하며 마무리합니다. 교재 예문: By Friday, right? 뜻: 금요일까지라는 말씀이 맞습니까?

연습 문제

각 문제의 정답과 이유를 바로 아래에 두었습니다. 먼저 스스로 써 본 뒤 확인하십시오. 답은 한 가지만 있는 것이 아니며, 핵심 내용과 확인 요청이 들어 있으면 자연스러운 답입니다.

고객이 다음과 같이 말합니다: We might need to push the launch back a little. So you mean으로 시작해 확인하는 문장을 한 줄로 써 보십시오.

예시답과 이유 보기

예시답: So you mean the launch will be later, right? 이유: push back은 일정을 뒤로 미룬다는 뜻이므로, 늦어진다는 핵심만 쉬운 말로 바꾸어 확인합니다.

고객이 다음과 같이 말합니다: We need 200 chairs in gray by the end of July. Let me make sure I understand로 시작해 세 가지 조건을 모두 확인해 보십시오.

예시답과 이유 보기

예시답: Let me make sure I understand. You need 200 chairs in gray by the end of July, right? 이유: 수량, 색상, 납기를 한 문장에 차례로 담고 right?로 맞는지 묻습니다.

빈칸에 알맞은 말을 쓰십시오: We can ___ ready by Monday.

예시답과 이유 보기

예시답: be 이유: ready는 형용사이므로 can 뒤에 be가 필요합니다.

고객이 납기일을 말했는데 날짜 부분을 놓쳤습니다. 영어로 다시 묻는 문장을 써 보십시오.

예시답과 이유 보기

예시답: Sorry, could you repeat the delivery date? 이유: 놓친 부분인 the delivery date만 짚어서 물으면 상대가 필요한 정보만 다시 말해 줄 수 있습니다.

새 상황입니다. 고객이 다음과 같이 말합니다: We'd prefer a different packaging size. Just to clarify로 시작해 내 말로 바꿔 확인하는 문장을 한 줄로 써 보십시오.

예시답과 이유 보기

예시답: Just to clarify, are you saying you want a different packaging size? 이유: prefer를 want로 쉽게 바꾸고, are you saying으로 상대의 뜻을 확인합니다.

알맞은 말을 고르십시오: If you (choice / choose) air shipping, we can deliver by May 20.

예시답과 이유 보기

예시답: choose 이유: if you 뒤에는 동작을 나타내는 동사가 와야 하므로 동사 choose를 씁니다.

03 직접 써 보세요

여러 조건을 한꺼번에 정리해 확인합니다.

예시답과 이유 보기

예시답: Let me make sure I understand. You need ..., right? 이유: 정답은 understand입니다. 조건을 수량, 색상, 날짜 순서로 한 문장에 담으면 빠진 조건이 없는지 쉽게 확인할 수 있습니다.

이어서 답해 보세요

주문이나 일정에서 수량, 색상, 날짜 세 가지 조건을 정하고 한 문장으로 확인해 보십시오.

예시답과 이유 보기

예시답: Let me make sure I understand. You need 1,000 bags in black by October 15, right? 이유: 세 가지 조건을 모두 담았고, 마감은 by로 나타냈습니다.
